# 로또 발매 애플리케이션
## 개요
사용자로부터 로또 구입 금액, 당첨 번호, 보너스 번호를 입력받은 후 로또를 발행하고 당첨 통계를 출력한다.

## 기능 요구 사항
- 로또 번호의 숫자 범위는 [1, 45]이다.
- 한 개의 로또를 발행할 때, 중복되지 않는 6개의 숫자를 뽑는다.
- 당첨 번호 추첨 시, 중복되지 않는 숫자 6개와 보너스 번호 1개를 뽑는다.
- 당첨은 1등부터 5등까지 있다. 당첨 기준과 각 금액은 다음과 같다.
  - 1등: 6개 번호 일치 / 2,000,000,000원
  - 2등: 5개 번호 + 보너스 번호 일치 / 30,000,000원
  - 3등: 5개 번호 일치 / 1,500,000원
  - 4등: 4개 번호 일치 / 50,000원
  - 5등: 3개 번호 일치 / 5,000원
- 로또 구입 금액을 입력하면, 구입 금액에 해당하는 만큼 로또를 발행해야 한다.
  - 로또 1장의 가격은 1,000원이다.
- 당첨 번호와 보너스 번호를 입력받는다.
- 사용자가 구매한 로또 번호와 당첨 번호를 비교하여 당첨 내역 및 수익률을 출력하고, 로또 게임을 종료한다.
- 사용자가 잘못된 값을 입력할 경우 `IllegalArgumentException`을 발생시켜 에러 메시지를 출력해야 한다.
  - 에러 메시지는 `[ERROR]`로 시작해야 한다.
  - 에러 메시지를 출력 후 그 부분부터 입력을 다시 받는다.
  - 예외는 `Exception`으로 처리하지 말고, 명확한 유형을 지정해 처리해야 한다.

## 구현할 기능 목록
### 입력
- [x] 로또 구입 금액을 입력받는다.
- [x] 당첨 번호를 입력받는다.
- [x] 보너스 번호를 입력받는다.
- [x] 사용한 자원을 반납한다.

### 출력
- [x] 구입금액 입력에 대한 안내 문구를 출력한다.
- [x] 발행한 로또 수량 및 번호를 출력한다.
  - [x] 로또 번호는 오름차순으로 정렬해 출력한다.
- [x] 당첨 번호 입력에 대한 안내 문구를 출력한다.
- [x] 보너스 번호 입력에 대한 안내 문구를 출력한다.
- [x] 당첨 통계를 출력한다. 수익률은 소수점 둘째 자리에서 반올림한다.
- [x] 예외 상황 시 에러 문구를 출력한다. 에러 문구는 `[ERROR]`로 시작해야 한다.

### 로또
- [x] 당첨 번호를 기반으로 비교를 위한 로또를 발행한다.
  - [x] 당첨 번호가 쉼표(,)로 구분되지 않으면 예외 처리한다.
  - [x] 6개의 번호로 구성되지 않는다면 예외 처리한다.
  - [x] 번호가 중복된다면 예외 처리한다.
  - [x] 보너스 번호가 당첨 번호와 중복된다면 예외 처리한다.
  - [x] 번호의 범위가 [1, 45]를 벗어난다면 예외 처리한다.
- [x] 금액 1,000원 당 하나의 무작위 로또를 발행한다.
  - [x] 금액이 1,000원으로 나누어 떨어지지 않는다면 예외 처리한다.
- [x] 로또의 당첨 결과를 계산한다.
- [x] 로또의 당첨 통계를 계산한다.

## 아키텍처
### model
- `InputParser`
  - 사용자의 입력을 적절한 객체로 파싱한다.
  - 구입 금액 입력이 숫자 형태의 값임을 검증한다.
  - 당첨 번호 입력이 적절한 구분자를 사용한 숫자 목록임을 검증한다.
  - 보너스 번호 입력이 숫자 형태의 값임을 검증한다.
- `Lotto`
  - 로또 한 장을 표현한다.
  - 로또 번호가 중복되지 않음을 검증한다.
  - 로또 번호의 개수를 검증한다.
- `LottoNumber`
  - 로또 번호를 표현한다.
  - 번호가 적절한 범위 안에 있음을 검증한다.
- `WinningLotto`
  - 당첨 번호와 보너스 번호에 대한 정보를 지닌다.
  - 보너스 번호가 다른 번호와 중복되지 않음을 검증한다.
  - 다른 로또와 비교하여 몇 개의 번호가 일치하는지를 계산한다.
  - 다른 로또가 보너스 번호와 일치하는지를 계산한다.
- `LottoPurchase`
  - 구입 금액을 통한 로또 발행을 책임진다.
  - 구입 금액이 로또 가격으로 나누어 떨어짐을 검증한다.
- `LottoResult`
  - 로또 당첨 결과를 표현한다.
- `LottoResultCalculator`
  - 로또를 당첨 번호, 보너스 번호와 비교하여 당첨 결과를 계산한다.
    - 즉, `Lotto`를 `WinningLotto`와 비교하여 적절한 `LottoResult`를 반환한다.
- `ResultAmounts`
  - 당첨 종류별 로또의 개수를 표현한다.
- `LottoAnalyzer`
  - 로또 당첨 결과를 기반으로 통계를 계산한다.
  - 당첨 종류별 로또의 개수와 총 수익률을 반환한다.

### View
- `LottoInputView`
  - 사용자의 입력을 읽는다.
- `GuideOutputView`
  - 안내 문구를 출력한다.
- `ErrorOutputView`
  - 에러 문구를 출력한다.
- `LottoOutputView`
  - 로또 구매 내역과 당첨 통계를 출력한다.
  - 로또 번호는 오름차순으로 정렬해 출력한다.
  - 총 수익률은 소수점 둘째 자리에서 반올림해 출력한다.

### Controller
- `LottoController`
  - 로또 애플리케이션의 실행 흐름을 담당한다.

### Configuration
- `LottoConfig`
  - 객체의 의존성을 관리한다.

### Util
- `RetryUtils`
  - 동작 발생 중 특정 예외가 발생할 경우 다시 시도하도록 한다.
  - 또한, 예외 발생 시마다 예외 핸들러를 호출한다.
